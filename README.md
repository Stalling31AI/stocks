# Stocks

A simple Python application for tracking and analyzing stock prices.

## Features

- Fetch real-time stock quotes
- Track portfolio performance
- Calculate basic statistics (average, min, max, change %)

## Requirements

- Python 3.8+
- `requests` library

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

## Project Structure

```
stocks/
├── main.py          # Entry point
├── stocks.py        # Stock data fetching and analysis
├── portfolio.py     # Portfolio management
├── requirements.txt # Dependencies
└── README.md        # This file
```
